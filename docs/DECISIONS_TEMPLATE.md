# Architecture Decision Record (ADR)

- **ID:** ADR-000
- **Title:** Short decision title
- **Status:** proposed | accepted | superseded
- **Date:** YYYY-MM-DD
- **Decision owner:** project lead
- **Affected areas:** frontend | backend | data | ML | database | deployment

## Context
What problem or constraint requires a decision?

## Options considered
1. Option A — benefits, costs, risks.
2. Option B — benefits, costs, risks.
3. Option C — if relevant.

## Decision
State the selected option and why.

## Consequences
List operational consequences, trade-offs, future migration costs and risks.

## Evidence
Add links to official documentation, measured test results, source feasibility or code review.

## Follow-up
List owner, task and validation criteria.

Do not use this template to present unverified assumptions as established facts.
