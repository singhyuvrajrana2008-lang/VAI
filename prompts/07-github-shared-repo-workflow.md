# Shared GitHub Workflow Prompt for Every Agent

The shared repository is https://github.com/singhyuvrajrana2008-lang/VAI. Read AGENTS.md before any work.

1. Verify the correct repository and current branch.
2. Pull the latest main.
3. Create a task branch using feat/, data/, docs/ or fix/.
4. Inspect assigned files and open PRs.
5. Do not create a second repository or detached copy.
6. Do not overwrite files owned by another agent without coordination.
7. Keep commits scoped and clear.
8. Open a PR to main; do not push directly to main by default.
9. Include test evidence, known limitations and setup notes.
10. Never commit secrets, protected data or model weights.
11. Coordinate any API, schema, migration, environment or shared type change.
12. If GitHub access is unavailable, say so and provide a patch; never claim a push happened.

Before coding, post a brief status including repository, branch, task, files to edit, contract dependencies and deliverable. At completion, state branch/PR, exact tests, verified integrations, missing secrets and known gaps.
